# 📚 StudyMate

An AI-powered study companion that helps students upload study materials, summarize notes, explain complex concepts, generate quizzes and flashcards, chat with documents, and organize study schedules using Google Gemini AI.

## 🌐 **Live Demo:** https://studymate-ai-susmita.ai.studio

---

## ✨ Features

- 📄 Upload PDF, DOCX, PPTX, and TXT files
- 🤖 AI-powered document summarization
- 💡 Explain complex concepts in simple language
- 📝 Generate key points and revision notes
- 💬 Chat with uploaded documents
- 🃏 AI-generated flashcards
- ❓ AI-generated quizzes (MCQs)
- 📅 Smart study planner
- 📊 Progress tracking dashboard
- 🔍 Research gap & future work suggestions
- 🔐 Secure authentication
- 🌙 Light & Dark Mode
- 📱 Fully responsive design

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Susmita0711/StudyMate-AI.git

cd StudyMate-AI
```

### Install Dependencies

Frontend

```bash
cd client
npm install
```

Backend

```bash
cd ../server
npm install
```

---

## ⚙️ Environment Variables

Create a `.env` file inside the backend folder.

```env
GEMINI_API_KEY=your_gemini_api_key

SUPABASE_URL=your_supabase_url

SUPABASE_ANON_KEY=your_supabase_anon_key

JWT_SECRET=your_secret_key
```

---

## ▶️ Run the Project

### Start Frontend

```bash
npm run dev
```

### Start Backend

```bash
npm run dev
```
